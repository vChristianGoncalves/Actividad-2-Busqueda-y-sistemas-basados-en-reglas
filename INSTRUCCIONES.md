# Sistema Inteligente de Rutas de Transporte Masivo 🚌

Este proyecto implementa un sistema inteligente para la planificación y optimización de rutas en una red de transporte masivo. Utiliza el paradigma de **Programación Lógica Declarativa** en Python para separar la **Base de Conocimiento** (hechos del mapa) del **Motor de Inferencia y Búsqueda** de caminos.

---

## 📋 Requisitos Previos

Antes de comenzar, asegúrate de contar con lo siguiente en tu sistema:
* **Python 3.8** o superior instalado.
* **Visual Studio Code** (o cualquier editor de texto/terminal de tu preferencia).

---

## 🚀 Guía Paso a Paso para la Configuración y Ejecución

Sigue detalladamente los siguientes pasos en orden secuencial:

### Paso 1: Clonar o Ubicar la Carpeta del Proyecto
Abre tu terminal (PowerShell, CMD, Git Bash o Terminal de macOS/Linux) y navega hacia la carpeta donde deseas guardar o donde ya se encuentra tu proyecto:

+ cd ruta/de/tu/carpeta

### Paso 2: Crear el Entorno Virtual (venv)

* python -m venv venv (Esto creará una carpeta llamada venv dentro del directorio de tu proyecto).

### En Windows (Símbolo del sistema / CMD):

* .\venv\Scripts\activate.bat

### Paso 3: Instalar las Dependencias del Proyecto

Con el entorno virtual activo (venv), instala la librería de programación lógica ejecuntado:

* pip install kanren

### Paso 4: Ejecutar el Proyecto

Con la terminal dentro del entorno activo (venv), lanza el script ejecutando:

* python main.py
